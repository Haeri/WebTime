# Security Policy

Please avoid publishing a suspected vulnerability before the maintainer has had a reasonable
chance to investigate it. Use the repository host's private vulnerability-reporting feature when
available; otherwise contact the maintainer privately through the account that publishes the
repository.

Useful reports include the affected macOS version, Web Time version, reproduction steps, expected
behavior, observed behavior, and any relevant logs with personal domains or addresses redacted.

Web Time is a personal friction tool, not parental-control or endpoint-security software. An
administrator of the Mac is outside its security boundary and can uninstall or modify the app.
